# План статьи (работа — позже)

Решение (2026-08-28): техрепорт = документация пакета (report/techreport.tex, финализирован);
статья — отдельный текст с тем, чего в репорте принципиально нет: **сравнением**.

## Ключевая рамка сравнения
Не «амортизированные пакеты друг против друга» (вне их области применимости — запрещено),
а **амортизированный вывод против по-инстансного байесовского счёта**: dynesty, nautilus,
tempered SMC, adaptive MH. Все методы в родной постановке; вопрос статьи — фронт цена-качество:
час обучения покупает точку «FID 0.003–0.08 за 70 мс» против «референс-качество за минуты» у
сэмплеров, плюс работа при недоступном правдоподобии (LV/Heston) и произвольных дизайнах.

## Что уже измерено (переносится из кампании)
- Стоимости на постериор всех движков (Table 3 репорта): <1 мс … 38 мин.
- Взаимная точность движков: HH двумя движками (SMC vs dynesty, лестницы в пределах сида);
  FHN худшие инстансы: dynesty vs SMC 0.012–0.018 sd; двухцепочечные полы всех систем.
- amortix против референсов: главная таблица (14 систем × 5 размеров, Muon).
- **nautilus-пилот (2026-08-28, инстанс 0, против наших референсов):**
  - FHN: 85 с, 19,500 вызовов logL, max расхождение 0.030 sd, ширины ×0.97–1.01;
  - HH: 343 с, 22,700 вызовов logL, max расхождение 0.042 sd, ширины ×1.00–1.02;
  - против dynesty: ~5× меньше вызовов, ~3× быстрее на HH. Скрипт: amortix_exp/nautilus_pilot.py.

## Чего не хватает для статейной таблицы
- Полная колонка nautilus (все 32+16 инстансов FHN/HH + применимые системы) — по слову.
- Единая таблица «метод × система»: расхождение с консенсусом (sd, FID) + сек/постериор +
  вызовы logL; amortix строкой.
- Возможное расширение d=20–30 (lingauss-25 точный; Lorenz-96 + dynesty/nautilus) — канон
  сообщества это покрывает (LogGamma-30, funnel-20, 25-D normal; bilby d=15 в проде).

## Стиль
Мантра: problem → interesting → unsolved → idea. Абстракт короткий безличный. Интро ≤1.5 стр,
в конце «Our main contributions are:». Без цифр в описании метода. Без рекламных идиом. Тире
экономно. Псевдокод — питоновский, в стиле Kaiming He.
